# libquantum-time-predictor

> Исследование в рамках проекта по теме "Разработка методики анализа и предсказания производительности программ на целевых архитектурах"  

Проинструментированный libquantum из набора SPEC CPU 2006 (открытый компонент, доступный в свободном доступе) для предсказания времени работы изначального бенчмарка с помощью упрощенного

## Структура проекта

### Директории
- src - проинструментированный иссходный код для сбора характеристик и параметров вызовов функций
- src_synt - код для запуска синтетического бенчмарка
- data - папка для сбора характеристик
- bdata - папка для хранения характеристик в бинарном виде
- bin - папка для исполняемых файлов

### Python-скрипты
- inertia.py - Создание графика для определения достаточного количества кластеров по методу локтя
- points.py - Кластеризация вызовов функции

### Bash-скрипты
- compile.sh - компиляция всех необходимых программ
- run.sh - полный цикл работы
